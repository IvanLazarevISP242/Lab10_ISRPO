# Практическая работа №2

## Поведение главного класса

Метод 1: `Restock(int amount)`
Что делает: Увеличивает количество товара на складе (`StockQuantity`), игнорируя неположительные числа.

Метод 2: `Sell(int amount)`
Что делает: Списывает проданный товар со склада, если передано положительное число и товара хватает в наличии. Возвращает `true` при успешной продаже или `false` при отказе.

Метод 3: `CalculateTotalCost(int quantity)`
Что возвращает: Итоговую стоимость (тип `double`) для указанного количества единиц товара на основе его текущей цены.
Почему эти действия относятся именно к этому классу:
Товар на складе характеризуется ценой и остатком. Учёт прихода, списание при покупке и расчёт стоимости партии — это базовые бизнес-правила самого товара, которые защищают его состояние (например, не дают остатку уйти в минус).
